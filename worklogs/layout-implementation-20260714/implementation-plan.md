## 實作策略

目前 theme 與影音資料匯入均有未提交變更。本輪新增 `assets/css/site-v3-layout-final.css`，並在既有 page foundation 之後載入。九組版型集中於這個覆寫層，避免重寫各頁模板或碰撞影音匯入。

需要拿掉的重複入口先以 CSS 隱藏：田間知識頁的上方六入口，以及田野誌最上方三入口。這保留可逆性，也不刪除內容。
