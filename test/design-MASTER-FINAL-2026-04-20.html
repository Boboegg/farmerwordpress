09 · 動畫 / 特效清單

核心鐵律：內容預設可見 · 動畫是加分不是必要 · hover 用 color / opacity 不用 scale（防 layout shift） · prefers-reduced-motion 全關
Hero Data-Split 逐字顯現
首屏載入 · hook-title .char
每個字 stagger transitionDelay `0.2 + i * 0.04s`，opacity 0→1 + translateY 10px→0。
Scroll Progress Bar
scroll 事件 · .v15-progress
頂部橫線寬度跟 scroll 百分比同步，主色漸層填充。
Scrolled Header State
scrollTop > 10 · body.scrolled
Header 縮小 + 背景霧化 + shadow 出現，用 transform 不動 height。
Topic / News / Media Card Stagger
reveal · IntersectionObserver
卡片進場 transitionDelay `i * 0.08s`（news/topic）或 `i * 0.06s`（media），opacity + translateY 30px。
Stat Count-Up
進視窗 · [data-count]
數字從 0 ease-out 跑到目標值，1.5s 內完成。中文數量大時用 Intl.NumberFormat 千分位。
Stat Scramble（章節頁用）
進視窗 · [data-scramble]
數字隨機字元亂跳 1s 後定住。章節頁 stat band 專用，比 count-up 更抓眼。
Tilt Card（partner 卡）
mousemove · [data-tilt]
滑鼠位置 → perspective 1000px + rotateX/Y ±5°，離開時回正。only hover 裝置。
Magnetic CTA
mousemove · [data-magnetic]
主 CTA 按鈕跟隨滑鼠 ±8px 位移，離開時彈回（cubic-bezier snap）。
Marquee 跑馬燈
CSS 無限 · @keyframes
章節關鍵字橫向無限滾動，中英混雜文案（比純文字飽滿），hover 時暫停。
Page Switcher 切章換色
select change · data-page
body[data-page] 變化 → CSS custom properties 切換，background transition 0.6s。
Partner Card Sticky（Feature Row）
CSS position: sticky
佐久 / 台大雲林 / 南佐久 partner 卡右欄 sticky top 120px，左欄內容滑過時卡片不動。
Hover Color Shift
:hover（@media hover: hover）
連結、卡片 hover 用 background-color / border-color 變化，不用 transform scale，防 layout shift。
Easing 常數：--v15-e-out: cubic-bezier(0.16, 1, 0.3, 1)（柔和減速，一般過渡）· --v15-e-snap: cubic-bezier(0.34, 1.56, 0.64, 1)（Q 彈回彈，CTA / magnetic 用）

10 · Don't List（嚴禁事項）

❌ 配色禁區：老茶米黃 #854D0E × 深咖啡（沉悶）· 純黑 #000 / 純白 #FFF（太硬）· 深咖啡當主色（老派政府公文感）· 灰階主調（農業是生命不是金融）· 單色調（7 章節必須有區辨度）

❌ 字體禁區：細體 serif（中高齡看不清）· 字級 < 18px 當正文 · 行高 < 1.75（東亞字體擠死）· letter-spacing < 0 用在中文

❌ 互動禁區：hover 用 transform scale（layout shift）· 動畫在首屏 > 0.2s delay（看到空白）· scrub 動畫動到 hero 文字 opacity（內容被吞）· emoji 當圖示（統一用 SVG Heroicons/Lucide）

❌ 內容禁區：AI 擅自改文案 / 數字 / 引用（2026-04-20 紅線） · 編造團隊成員 / KPI / 期刊名 · 部署前未跑 content diff 驗證

❌ 動畫強度：matrix / cyberpunk / HUD / scanner 軍事感（本案是紀錄片電影感，非 sci-fi）
